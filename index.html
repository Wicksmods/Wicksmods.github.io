Beta build, hosted on GitHub

Forever is still in beta, so the suite is too. One zip holds WickCore, the bags, the comforts, the levelling gear browser, the trade hall and every class kit. Drop the folders into _classic_beta_\Interface\AddOns and they are ready.

1 Download the zip and close World of Warcraft.
2 Open your game folder, then _classic_beta_ › Interface › AddOns. Create the AddOns folder if it is not there.
3 Copy every folder from inside the zip into AddOns, start the game, and tick them in the AddOns list.
Download the zip Release notes →
Known issue on the beta client: the game writes settings correctly and never reads them back, so nothing you configure survives a reload. It affects every addon you have, not only these. WickCore can keep your Wick settings anyway, in a handful of macros, which live on Blizzard's servers and so survive a relog, a restart and a different PC. It is off until you ask for it with /wickcore store on, it only keeps what you changed from the defaults, and it never touches your own macros. If Blizzard fixes the client it notices and stays out of the way.

Wick's Gear
What to chase while levelling, a browser for what drops where, and a paperdoll to try pieces on: right-click anything to see what it would do to your stats, green up and red down. Ships item ids and nothing else, so every number comes from your own client.

GitHub
Wick's Trade Hall
What a run earned and what trade chat is offering, in one window. The session side values loot at vendor price and marks what it cannot price rather than guessing; the board keeps one line per person per subject, sorted into selling, buying, enchanting, crafting and travel. It reads the channel and never posts.
